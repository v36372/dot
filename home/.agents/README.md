# Shared Agent Skills

This directory is stowed to `~/.agents`, which Pi discovers natively.

- `skills/` contains committed personal and third-party skills.
- `.skill-lock.json` is generated by the `skills` CLI for tracked upstream skills.
- Personal skills are not added to the lock and are never touched by upstream syncs.

Run `./dot skills-sync` from the dotfiles repository to update every skill in
the lock, regardless of its upstream source. Personal skills without lock
entries are untouched. Review `git diff -- home/.agents` before committing.

Use `skill-add <source> [skill-name ...]` from Fish to install and lock skills
from additional upstream sources.

Do not run the installer with `--agent pi`; that writes duplicate copies under
`~/.pi/agent/skills`. The sync command targets the shared `~/.agents/skills`
location directly.
